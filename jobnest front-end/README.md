# JobNest Front-End

A responsive, front-end-only job board inspired by the supplied layout.

## Run
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Features
- Responsive desktop and mobile layout
- Job search by title, company, skill, or location
- Popular search and category filters
- Company filters
- Demo Apply buttons and resume file selection feedback
- Sign-up and notification demo messages

All interactions are front-end demonstrations. No backend, account system, or real job application submission is connected.
